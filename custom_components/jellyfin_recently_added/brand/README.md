# Brand assets

`icon.png`, `logo.png` (and their `@2x`/`dark_*` variants) are Jellyfin's own icon
and logo, copied unmodified from the official [home-assistant/brands](https://github.com/home-assistant/brands/tree/master/core_integrations/jellyfin)
repository — the same assets used by Home Assistant core's built-in Jellyfin
integration.

Since Home Assistant 2026.3.0, custom integrations can bundle their brand
assets directly here instead of submitting them to home-assistant/brands (see
the [Brands Proxy API announcement](https://developers.home-assistant.io/blog/2026/02/24/brands-proxy-api)).
This is what satisfies HACS's brand-asset validation for this repository.

solely to identify the Jellyfin server this integration connects to; their
use does not imply endorsement by, or affiliation with, the Jellyfin project.
